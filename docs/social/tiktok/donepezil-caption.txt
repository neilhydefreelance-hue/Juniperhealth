Donepezil: Alzheimer's medicine explained 💊

🧠 It can help with memory and thinking for a while in Alzheimer's disease, but it does not cure it
🤢 Common side effects: feeling sick, diarrhoea, vivid dreams, muscle cramps and tiredness
🌙 It is usually taken at night. If it causes vivid dreams, taking it in the morning may help
📉 Stopping can lead to a drop in memory and thinking within weeks. Decide with the memory clinic or GP
🩺 Get help for a slow heartbeat or fainting, black or bloody poo, vomiting blood, or fits
